# BON Web

BON Web is an ASP.NET Core MVC web application developed for presenting and managing BON products and customer orders.

The application includes a product catalog, category filtering, product search, shopping cart, checkout system, contact form and an administration section for managing orders.

## Features

- Product catalog
- Product details
- Product search
- Category filtering
- Shopping cart
- Increase and decrease product quantity
- Remove products from cart
- Checkout and order creation
- Order history for administrators
- Order status management
- Admin authentication and authorization
- Contact form with email functionality
- Online BON product catalog
- Responsive user interface
